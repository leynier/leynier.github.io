# Cuba Weather - De Cuba Para Cuba

> Leynier Gutiérrez González | October 24, 2020

![header.png](<https://cdn.hashnode.com/res/hashnode/image/upload/v1624881930665/GA15WR_kI.png> align="left")

**Cuba Weather** es un proyecto pionero en Cuba de código abierto, multiplataforma y sin ánimo de lucro. Su objetivo es proporcionar a los residentes en Cuba una manera cómoda de acceder a información meteorológica de fuentes nacionales utilizando solo navegación nacional (por ejemplo, el bono de 300 megabytes nacionales de los paquetes de datos). En poco más de un mes en Apklis, ha alcanzado más de 27,000 descargas, ha sido reportado en varios medios digitales, y ha recibido una gran contribución de los usuarios mediante sugerencias y donaciones. Además, ha contado con la colaboración y asesoramiento de especialistas del INSMET y mejoras implementadas por varios desarrolladores, creando rápidamente una comunidad entusiasta alrededor del proyecto.

El proyecto es de código abierto, ya que uno de sus objetivos es fomentar el software libre y el código abierto en Cuba. Todo el código relacionado con el proyecto se encuentra disponible en GitHub bajo la organización Cuba Weather ([https://github.com/cuba-weather](https://github.com/cuba-weather)).

Para el desarrollo de la aplicación Android se utilizó Flutter, el SDK de código abierto para el desarrollo de aplicaciones móviles creado por Google. Flutter se utiliza comúnmente para desarrollar interfaces de usuario en aplicaciones para Android, iOS y Web, y es el método primario para crear aplicaciones para Google Fuchsia.

La aplicación utiliza información meteorológica extraída exclusivamente de fuentes nacionales, eliminando la necesidad de navegación internacional y ampliando las opciones disponibles con la navegación nacional, diferenciándose de otras aplicaciones y contribuyendo a la informatización del país.

En la versión actual, la aplicación obtiene datos del sitio web oficial del Instituto de Meteorología de Cuba ([http://www.insmet.cu](http://www.insmet.cu)), incluyendo pronósticos extendidos del día actual y del siguiente, perspectivas del tiempo y pronósticos a varios días. Además, se extrae información del buscador cubano RedCuba ([https://www.redcuba.cu](https://www.redcuba.cu)), como la temperatura, humedad, presión atmosférica y velocidad y dirección del viento, con un período de actualización de 2 a 3 horas.

El proyecto ha contado con la colaboración de reconocidos meteorólogos como Elier Pila, la comunidad de desarrolladores de Cuba y los usuarios, quienes han contribuido de diversas formas, incluyendo donaciones. Estas donaciones se utilizan para pagar infraestructura como el dominio ([https://cubaweather.app](https://cubaweather.app)), un hosting de Etecsa para la versión web del proyecto y licencias de desarrollador para las principales tiendas (Google Play y Apple Store). En ningún caso, estas donaciones se utilizan para beneficio propio de los desarrolladores.

Actualmente, está disponible una aplicación para Android publicada en Apklis ([https://www.apklis.cu/application/com.codestrange.www.cuba\_weather](https://www.apklis.cu/application/com.codestrange.www.cuba_weather)).
