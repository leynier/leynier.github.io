# Privacy Policy

Last updated: November 8, 2026

This policy covers **gog CLI**, a personal command-line tool that Leynier Gutiérrez González uses to work with his own Google accounts (Gmail, Calendar, Drive, Docs, Sheets, Contacts, and Tasks). It is not offered to the public.

## Data accessed

When an account owner signs in and grants consent, gog CLI can read and, when the owner explicitly asks, change data in the Google services listed above for that account only.

## How data is used

Data is used only to perform the action the account owner requests from the command line, such as listing messages, creating a draft, or reading a calendar event. It is not used for advertising, profiling, or training models, and it is not sold or transferred to third parties.

## Storage

OAuth tokens are stored on the owner's own computer in an encrypted keyring. Google data is processed locally and is not sent to any server operated by this app. Files the owner chooses to download are stored on the owner's computer.

## Google API Services User Data Policy

gog CLI's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time from [Google Account permissions](https://myaccount.google.com/permissions). Removing the app there invalidates its tokens immediately.
